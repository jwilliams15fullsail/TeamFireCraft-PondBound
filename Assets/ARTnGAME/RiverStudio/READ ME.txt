River Studio

InfiniRIVER is the new Fluid based water simulator for Unity by ARTnGAME. 
The system can emulate the interaction of water with scene objects in 
real time using a fluid solver and do so in a global or local way for 
versatility and cover of all use cases.

InfiniRIVER is in its first release and will be in Beta for some time 
until all features are fully realized. The base fluid system is production 
ready and more work on usability and control of the effect will be added 
in the various Beta stages for more options.

----------------------- BASIC PIPELINES SETUP -----------------------

InfiniRIVER has been build around support for all pipelines, the development was carried out
while having all 3 pipelines installed (SRP, URP and HDRP) at the same time, thus a number
of actions is required if need to use only one of the URP or HDRP pipelines.

The store download defaults to Standard Pipeline. For use with HDRP or URP do the following:

The files mentioned below have some defines (#define HDRP and #define URP)
In the case all pipelines is installed then all defines should be active (as is the default)

InfiniRIVER_Water_SETUP
DepthRendererCT_HDRP_VOLUME
DepthRendererCT_HDRP
DepthRendererCT_URP

For convinience a number of direct installer packages with the various file variations of the defines
is included in the "0 INSTALL PIPELINES" folder.

To setup for only Standard Pipeline please comment out both the #define HDRP and #define URP
lines at the top of the above scripts OR install the "Install if only STANDARD PIPELINE is used" package

To setup for only URP Pipeline please comment out the #define HDRP
lines at the top of the above scripts OR install the "Install if only HDRP PIPELINE is used" package

To setup for only HDRP Pipeline please comment out the #define URP
lines at the top of the above scripts OR install the "Install if only URP PIPELINE is used" package

If all pipelines are installed at the same time, uncomment all defines 
OR install the "Install if all Pipelines installed same time" package


----------------------- QUICK START WITH PREFAB -----------------------

Drag the "COMPLETE RIVER PREFAB" prefab inside the RiverStudio -> PREFABS folder to
the scene. Configure the system for the various modes and pipelines using the 
"RIVER WATER CREATE and CONFIG" script.


----------------------- QUICK START WITH PREFAB MAKER -----------------------

Open "AUTO CONFIGURE PREFAB DEMO" demo scene. Enable the relevant SAMPLE SCENE object
and disable the rest based on used pipeline.

In "RIVER WATER CREATE and CONFIG" script (InfiniRIVER_Water_SETUP), press the "Insert Prefabs"
checkbox to create the water.

Then choose the pipeline mode and other options (e.g. world space mode) and press the 
"Setup Water" checkbox. This checkbox can be pressed again if other options are chose to
reconfigure the system as needed.

At this point a prefab with all the required items can be created and dragged to any other scene.
